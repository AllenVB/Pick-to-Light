03 / 14
Işık Mantığı

Hangi renk ne zaman yanar?

s = mevcut stok · q = sipariş miktarı · b = güvenlik stoğu (buffer)
YEŞİL
Stok Yeterli
s ≥ q + b
Sipariş sonrası bile güvenlik stoğu korunur. Ürün rahatça verilir, sistem stoğu otomatik düşer.
SARI
Stok Azaldı
q ≤ s < q + b
Sipariş karşılanır ama kritik seviyeye inilir. Uyarı gösterilir ve tedarik talebi açılır.
KIRMIZI
Stok Yetersiz
s < q
Alarm! LED hiç yanmaz, ekrana uyarı basılır, sipariş kilitlenir, tedarik tetiklenir.

Stok Tutarlılığı

Önce stoğu düş, sonra siparişi onayla

Kontrol ve düşme tek bir atomik işlemde yapılır; böylece "ışık yeşil ama ürün yok" durumu (yarış koşulu) oluşmaz. Kırmızı, daha sipariş kabul edilirken yakalanır — kutuya hiç yansımaz.
KURAL
1
Stoğu düş (atomik + kilitli)Sistem, siparişi kabul etmeden önce stoğu koşullu ve kilitli olarak düşürür.
2
Sonra onaylaDüşme başarılıysa sipariş onaylanır ve kutunun LED'i yanar.
UPDATE stok SET adet = adet - q
WHERE kutu_id = ? AND adet >= q;
-- etkilenen satır = 0  →  stok yetersiz

✓  Düşme başarılı → sipariş onay

LED yeşil/sarı yanar · operatör ürünü alır · stok hareketi loglanır.

🔒  Düşme başarısız (s < q) → KİLİT

Sipariş kilitlenir · ekrana "stok yok" uyarısı basılır · tedarik talebi açılır. Kutu kırmızıya dönmeden işlem durur.

Üç savunma hattı: koşullu UPDATE · CHECK (adet ≥ 0) kısıtı · versiyon alanıyla optimistic lock.

Donanım Tasarımı

Kutu, LED ve kontrolcü — elektrik ekibi

KARE MODÜLER KUTU
Modüler: kutular yan yana çoğaltılabilir

Mikrodenetleyici

ESP32 (Wi-Fi dahili) — LED'i sürer, sensörü okur, MQTT ile konuşur.

Durum LED'i

Kutu başına WS2812B RGB veya yeşil/sarı/kırmızı 3'lü LED + sürücü direnci.

Onay sensörü

Buton (v1), IR mesafe ya da HX711 ağırlık sensörü — 'ürün alındı' teyidi verir.

Güç

Ortak 5 V hat; kutular paralel beslenir, tek adaptörden dağıtım, ortak GND.

Ortak Dil

MQTT sözleşmesi — iki ekibin buluştuğu nokta

Bu sözleşme 2. hafta sonunda dondurulur; sonrasında iki ekip birbirini beklemeden paralel ilerler.
TopicYönQoS
depo/kutu/{id}/komutSunucu → Cihaz1
depo/kutu/{id}/olayCihaz → Sunucu1
depo/kutu/{id}/durumCihaz → Sunucu1 · retained
depo/kutu/{id}/telemetriCihaz → Sunucu0
  • İdempotenlik: her komut mesajId taşır, teyit aynı id ile döner — çift düşme olmaz.
  • LWT: kutu koparsa broker 30 sn içinde OFFLINE yayınlar.
// LED yakma komutu (sunucu → cihaz)
{ "mesajId": "8f1c…",
  "tip": "LED_YAK",
  "renk": "YESIL",
  "miktar": 3,
  "ttlSn": 300 }

// Teyit olayı (cihaz → sunucu)

  "tip": "TEYIT",
